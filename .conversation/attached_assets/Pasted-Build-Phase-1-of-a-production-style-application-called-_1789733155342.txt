Build Phase 1 of a production-style application called **Ordriva — Distributed Order & Fulfillment Platform**.

IMPORTANT:
This is not a basic e-commerce shopping website. Ordriva is an enterprise engineering platform for managing high-volume orders, inventory, warehouses, payments, fulfillment, system events, and operational analytics.

For this phase, focus ONLY on creating a polished frontend and frontend architecture. Do not fake a completed backend. Use clearly separated mock data/services that can later be replaced by real REST APIs.

TECHNOLOGY:

* React
* TypeScript
* Tailwind CSS
* Reusable component architecture
* Responsive design
* Chart library suitable for operational dashboards

DESIGN:
Create a modern enterprise SaaS dashboard.
The interface should look like a real logistics/order-management product rather than a student project.

Use:

* Professional sidebar navigation
* Top navigation bar
* Clean typography
* Responsive cards
* Data tables
* Charts
* Status badges
* Modals/drawers
* Toast notifications
* Loading states
* Empty states
* Error states
* Pagination
* Search
* Filters

ARCHITECTURE:

Create the frontend in a way that every mock service can later be replaced with actual backend API calls without redesigning pages.

Do not implement AI/RAG/chatbot features. This project's purpose is distributed systems and backend engineering.

At the end, verify:

* Every navigation item works
* No broken pages
* Responsive layouts work
* Components are reusable
* No unnecessary placeholder pages
